# RecoveryMap — təkmilləşdirilmiş mənbə faylları

Bütün faylları eyni qovluğa qoyun. Yer şəklini assets/earth-mission.webp yolunda saxlayın.

İşə salmaq: python3 -m http.server 8000
Windows: py -m http.server 8000
Brauzer: http://localhost:8000

index.html — struktur; style.css — dizayn; app.js — tətbiq; csv.js — CSV oxuyucu və tarix yoxlaması; sw.js — oflayn keş.

Təkmilləşdirmələr: dırnaqlı və çoxsətirli CSV sahələri, dəyişən sütun sırası, tarix və rəqəm yoxlaması, buraxılmış sətirlərin sayı; köhnə keşlərin təmizlənməsi, resurs növünə uyğun oflayn cavab; mobil toxunma sahələri və azaldılmış animasiya seçimi.

Şəxsi qeydlər lokal brauzer yaddaşındadır. Demo göstəricilər sintetikdir. PDF/DOCX çıxarışı və kamera izləmə inteqrasiya edilməyib. Bu ayrıca kod paketidir; yayımlanmış sayt dəyişdirilməyib.
